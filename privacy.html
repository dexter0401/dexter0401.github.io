bisil 개인정보처리방침

시행일: 2026년 11월 16일

1. 이용하는 정보

bisil은 개발자 본인의 구글 계정에 대해, 본인이 허용한 범위에서 구글 캘린더의 캘린더 목록과 일정(제목, 시간, 메모)에 접근합니다.

2. 이용 목적

일정을 화면에 보여 주고, 본인이 요청한 일정을 추가·수정·삭제하고, 일정 알림을 본인의 기기로 보내는 데에만 씁니다.

3. 저장과 공유

구글에서 받은 정보는 개발자 본인의 컴퓨터에서만 처리됩니다. 제3자에게 판매하거나 공유하지 않으며, 광고에 쓰지 않습니다.

4. 구글 API 서비스 사용자 데이터 정책

bisil이 구글 API에서 받은 정보를 사용하고 다른 앱으로 전송하는 것은 제한적 사용 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.

5. 접근 철회

구글 계정 설정의 '서드 파티 앱 및 서비스'에서 언제든지 bisil의 접근 권한을 해제할 수 있습니다.
